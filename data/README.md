# Data Folder README

This folder contains all of the relevant data files for this project. Note that only my data files under 100 MB are pushed to GitHub. My data files larger than 100 MB are available on the class server. Data files are organized into folders matching the analysis file in "Amplicon_Project/analysis" where the data file was used/generated.

Please see the README in "Amplicon_Project/analysis" for more information about each analysis document this data was used in or generated from.
